# Katun Checkout for Agents

Demonstration repository for the Airwallex Agentic Banking Hackathon 2026 (track 10, Merchant-Enabled Agentic Checkout).

This repository contains what a third party needs to reproduce the demonstration against the public Katun sandbox (`https://sandbox.katunpay.com`). It does not contain Katun itself. Everything here runs against the sandbox, with synthetic data and test cards; no money moves.

Status: skeleton. The demonstration, the video and the step-by-step instructions land here during the build phase (27 October to 13 November 2026). Until then, the README describes only the purpose and the layout.

## Purpose

Show, end to end and reproducibly:

1. A buyer in Claude finds products of a synthetic merchant through the merchant's Katun connector.
2. An order above the merchant's limit waits for a human approval.
3. Payment runs in the Airwallex sandbox with a test card.
4. The merchant returns its order number and a signed receipt that anyone can verify offline.
5. In a second scene, an autonomous buying agent identifies itself with a Visa Trusted Agent Protocol signature (RFC 9421, Ed25519), and the merchant verifies it before accepting the order.

## Layout

```
catalog/     synthetic catalog of 100 products and the script that generates it in the sandbox CSV format,
             plus the steps to load it in the Katun sandbox panel
tap-agent/   demonstration buying agent: Ed25519 key generation, a Trusted Agent Protocol signer (RFC 9421),
             and the JWKS directory the agent publishes
verify/      script that downloads the public keys, the verifier and a receipt from the sandbox and verifies
             the receipt offline
scripts/     reproduction scripts (environment check, demo walkthrough) and their notes
docs/        notes: what was verified in the public specifications and when (tap-notes.md), the architecture
             diagram and the demo script (to come)
```

## What this repository is not

- It is not the Katun source code. Katun is a separate, private codebase; this repository only talks to its public sandbox over HTTP.
- It does not contain keys, credentials or any production URL. Private keys generated by `tap-agent/keygen.mjs` are written outside the tracked tree and ignored by git.
- It does not include code from Visa. The signer is written from the public specification; Visa's sample code is under Visa's own terms and is not copied here.

## Requirements

Node.js 22 or newer and `curl`. No package installation is needed: the scripts use only Node's standard library.
